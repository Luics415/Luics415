# Luics415 Profile V3

Copia todo este paquete en la raíz de `Luics415/Luics415`.

Cada sección del README usa `<picture>`:
- GIF local para la animación.
- SVG local como respaldo estable.

Por tanto, el perfil no depende de GitSkins ni de ningún endpoint externo para estos cinco bloques.

`stack` y `projects` se regeneran cada 6 horas mediante GitHub Actions. También se pueden actualizar manualmente desde:

**Actions → Update profile visuals → Run workflow**

Archivos principales:

- `assets/hero.svg`
- `assets/chess.svg`
- `assets/stack.svg`
- `assets/projects.svg`
- `assets/social.svg`

Las versiones `.gif` son las animadas y los cinco `.svg` permanecen como fallback.
