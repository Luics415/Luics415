# Iconos de contacto

Los iconos de GitHub, WhatsApp y ubicación proceden de Bootstrap Icons
`v1.13.1`. Se guardan localmente para que el perfil no dependa de recursos
externos al visualizarse.

- `icons/github.svg`
- `icons/whatsapp.svg`
- `icons/geo-alt-fill.svg`, guardado aquí como `location.svg`

Las formas se conservan sin redibujarlas. Los PNG son rasterizaciones locales
de los mismos SVG para componer los GIF. Bootstrap Icons se distribuye bajo
licencia MIT; la copia se incluye en `BOOTSTRAP_ICONS_LICENSE`.
